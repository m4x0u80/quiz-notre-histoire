# Notre histoire ♡

Un questionnaire romantique de 12 questions, sans mauvaises réponses.

## Tester
Ouvrir `index.html` dans un navigateur.

## Mettre en ligne avec GitHub Pages
1. Créer un dépôt GitHub public.
2. Ajouter `index.html`, `style.css`, `script.js` à la racine du dépôt.
3. Dans **Settings > Pages**, choisir **Deploy from a branch**, branche **main**, dossier **/(root)**, puis **Save**.
4. Attendre la publication puis ouvrir l'URL fournie par GitHub Pages.

## Personnaliser
Dans `script.js`, modifier les tableaux `musics` et `photos` (placeholders pour l'instant). Les fichiers audio et les photos seront intégrés dans une prochaine version.

## Télécharger le récapitulatif
Le bouton final ouvre la boîte d'impression du navigateur : choisir **Enregistrer au format PDF**. Les réponses sont sauvegardées uniquement dans le navigateur via `localStorage`.

Attention : les fichiers d'un site GitHub Pages public sont accessibles aux visiteurs. Ne pas y placer de contenu privé sans protection adaptée.
